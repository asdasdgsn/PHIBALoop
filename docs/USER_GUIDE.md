# 使用指南

[返回 README](../README.md)

## 1. 添加 GIF 与预览

点击工具栏的“添加 GIF”或从 Finder 拖入 GIF，可以一次添加多个文件。左侧列出任务状态和基础信息，中间播放所选 GIF。相同文件不会重复加入队列。

右侧修改通常作用于当前选中的任务；选择多个任务后，可以批量应用参数。“开始转换”会处理队列中尚未完成的任务，不仅是当前选中的一项。

## 2. 输出格式

| 格式 | 透明背景 | 适用情况 |
| --- | --- | --- |
| HEVC / H.265 MP4 | 不保留 | 不需要透明背景的动画视频 |
| Apple HEVC Alpha MOV | 支持 | 需要叠加到应用、网页或其他画面中的透明动画 |

具体编码能力取决于 Mac 和 macOS。遇到不支持所选格式的错误时，请记录设备、系统与格式信息，不要将失败文件当作有效输出。

## 3. 透明处理

- **关闭**：以填充色合成不透明画面。
- **保留原透明**：保留 GIF 解码后的透明像素；不会自动去除绿色或白色背景。
- **纯色抠除**：选择背景色，调整容差和边缘柔化。绿色背景还可启用绿色溢色抑制。

容差过大可能误删主体颜色，过小则可能留下背景；先用短小的素材试导出。MP4 无论选择什么透明参数，最终都以不透明形式输出。

## 4. 尺寸、帧率、质量与循环

- 可使用原始尺寸、75%、50%，或填写自定义宽高。自定义尺寸不自动锁定比例。
- 视频编码尺寸会调整为不小于 2 的偶数；奇数宽高可能减少 1 像素。
- 原始帧率模式保留 GIF 的帧时序。24/30/60 fps 通过重复采样帧实现，不做运动补帧，实际时长可能存在取整差异。
- 质量档影响目标码率，不保证固定文件大小。
- 重复次数控制将整段动画写入视频的次数，并非播放器的永久循环指令。

## 5. 导出与取消

左下角显示实际目标目录，默认使用系统“影片”目录。点击“更改…”后选择目标文件夹，再开始转换。同名结果会自动添加后缀，避免覆盖已有文件。

完成后可在 Finder 中定位输出。程序会验证视频轨道、尺寸和时长；未通过验证的任务会显示失败，不应仅凭磁盘出现文件就认定转换成功。取消为协作式取消，编码器退出当前处理后才完成停止，已完成的任务不会自动删除。

## 6. 常见问题

### 透明 MOV 看起来是黑底

播放器或目标程序可能不支持 HEVC Alpha，或用黑色展示透明区域。请在支持该格式的目标应用中，叠加到另一种背景上检查。不要只根据单个播放器的黑底画面判断。

### 文件变大了

较大的分辨率、较高码率、重复次数或固定帧率增加帧数，都可能增大文件。可尝试减少尺寸或使用小体积档。

### 导出的文件夹不对

以左下角显示的完整路径为准。导出开始时会固定本轮目标目录，运行过程中更改目录不应被理解为迁移正在写入的任务。

### 素材无法导入或转换失败

当前只接受可解码 GIF；损坏文件、部分编码能力缺失或没有输出目录写入权限都可能导致失败。反馈时提供系统版本、芯片、参数与可公开的最小复现素材。不要上传私人照片或商业保密素材。
