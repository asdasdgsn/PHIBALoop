# PHIBALoop 1.0.1 · 图标更新预览版

- 使用新的透明底应用图标，保留蓝色底板、魔法棒、闪电和棋盘格设计。
- 安装包内包含多尺寸 macOS 图标。
- GIF 转 HEVC MP4、透明 HEVC Alpha MOV 等功能保持一致。

## 下载与安装

下载 `PHIBALoop-1.0.1-AppleSilicon.dmg`，打开后将 PHIBALoop.app 拖入“应用程序”，替换旧版前请先退出应用。附 SHA-256 校验文件。

适用于 Apple Silicon Mac，最低 macOS 13。此预览包为临时签名，尚未经过 Apple 公证，系统可能阻止直接打开。应用图标图片的权利独立于代码的 MIT 许可证。
